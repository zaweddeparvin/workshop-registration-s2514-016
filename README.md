## Project Description

Campus Create is a responsive workshop registration page built for the HTML, CSS and JavaScript Workshop Registration Lab. It demonstrates HTML form controls and constraints, CSS Grid responsive styling, JavaScript arrays and loops, custom validation, browser validation and individual/group booking logic.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive two-column registration form
- Email, URL, date and number input constraints
- Telephone format validation
- Practice password and confirmation validation
- Workshop choices generated from a JavaScript array and loop
- Browser validation using `reportValidity()`
- Individual booking for one seat
- Group booking for two to four seats
- Accessible focus styles and responsive mobile layout
- Success and error feedback

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Enter invented practice details.
5. Select a workshop and a valid date.
6. Enter a practice password of at least 10 characters and confirm it.
7. Tick the agreement checkbox.
8. Click **Preview registration**.

This is a browser-only classroom demonstration. It does not create an account, send a request, or save registration details.
